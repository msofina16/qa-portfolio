# Sauce Demo — тестирование интернет-магазина

**Сайт:** https://www.saucedemo.com
**Тип тестирования:** ручное функциональное тестирование (веб)
**Браузер:** Google Chrome, последняя версия
**Тестировщик:** Мария Софина

## Тестовые пользователи

Пароль у всех: `secret_sauce` (он публично указан на главной странице сайта).

| Логин | Особенность |
|---|---|
| standard_user | обычный пользователь, всё работает |
| locked_out_user | заблокированный пользователь |
| problem_user | пользователь, у которого на сайте специально сделаны дефекты |
| performance_glitch_user | сайт отвечает медленно |
| error_user | на некоторых действиях появляются ошибки |
| visual_user | есть визуальные дефекты |
